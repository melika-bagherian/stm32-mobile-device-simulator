# STM32 Mobile Device Simulator 📱

یک سیستم Embedded مبتنی بر **STM32** که با هدف شبیه‌سازی یک دستگاه موبایل ساده طراحی و پیاده‌سازی شده است.

این پروژه شامل چندین ماژول مستقل است که کاربر می‌تواند از طریق منوی اصلی بین آن‌ها جابه‌جا شود. رابط کاربری سیستم با استفاده از **LCD 20×4** و کلیدهای فیزیکی پیاده‌سازی شده و بخش‌هایی مانند پخش موسیقی، یادداشت‌ها، مخاطبین، تنظیمات، اطلاعات سیستم و یک بازی تعاملی را شامل می‌شود.

## 🧩 معماری کلی سیستم

سیستم به صورت **State-Based** طراحی شده است.

هر بخش از برنامه یک State مشخص دارد و بر اساس State فعلی، منطق مربوط به همان بخش اجرا می‌شود.

برای مثال:

```text
APP_LOGO
   ↓
APP_MENU
   ├── Music Player
   ├── Contacts
   ├── Notes
   ├── Game
   ├── Settings
   └── Info
```

بخش Game نیز Stateهای داخلی خودش را دارد و منطق منو، بازی، تنظیمات و پایان بازی را از یکدیگر جدا می‌کند.

## ⚙️ Peripheralها و تکنولوژی‌های استفاده‌شده

### GPIO & External Interrupt

کلیدهای فیزیکی از طریق GPIO به میکروکنترلر متصل شده‌اند و برای دریافت ورودی کاربر از **External Interrupt (EXTI)** استفاده شده است.

ورودی‌های مختلف برای کنترل بخش‌هایی مانند:

- حرکت در منو
- انتخاب گزینه
- کنترل بازی
- تعامل با Contact و Notes

استفاده می‌شوند.

---

### ADC

از ADC برای دریافت مقادیر آنالوگ استفاده شده است.

#### LDR

مقدار LDR برای تشخیص وضعیت محیط استفاده می‌شود:

```text
ADC Value
   │
   ├── > 2000 → DAY
   │
   └── ≤ 2000 → NIGHT
```

این وضعیت در منطق بازی مورد استفاده قرار می‌گیرد.

#### Potentiometer

همچنین ورودی Potentiometer در پروژه برای دریافت مقدار آنالوگ و تبدیل آن به محدوده مورد نیاز سیستم پیاده‌سازی شده است.

---

### UART

از **UART** برای دریافت ورودی و تنظیم برخی پارامترهای سیستم و بازی استفاده شده است.

برای مثال، در هنگام تنظیم بازی می‌توان تعداد گیاهان و نحوه تقسیم آن‌ها در شرایط مختلف را مشخص کرد.

---

### Timer & PWM

از Timer و PWM برای تولید صدای Buzzer استفاده شده است.

این بخش در:

- Music Player
- موسیقی پس‌زمینه بازی
- تولید Toneهای مختلف

به کار گرفته شده است.

---

### LCD 20×4

رابط کاربری اصلی پروژه با استفاده از یک LCD 20×4 طراحی شده است.

برای ایجاد رابط گرافیکی ساده‌تر نیز از **Custom Character**های LCD استفاده شده است.

این Custom Characterها برای نمایش عناصر مختلف مانند:

- Human
- Plant
- Contact
- Notes
- Music
- Settings
- Info
- Zombie
- Shield
- Heart

استفاده شده‌اند.

## 🎮 منطق بازی

بازی یکی از ماژول‌های سیستم است و منطق آن شامل چند بخش اصلی است:

```text
Game
├── Game Menu
├── Game Settings
├── Plant Selection
├── Zombie Spawn
├── Zombie Movement
├── Plant Attack
├── Bullet Movement
├── Health System
```

حرکت و وضعیت موجودات بازی با استفاده از منطق State و زمان‌بندی مبتنی بر `HAL_GetTick()` مدیریت می‌شود.

## 🚀 نحوه اجرای پروژه

برای اجرای پروژه:

1. پروژه را Clone کنید:

```bash
git clone <repository-url>
```

2. پروژه را در **STM32CubeIDE** باز کنید.

3. فایل `final.ioc` را در صورت نیاز در STM32CubeMX/CubeIDE بررسی کنید.

4. سخت‌افزار مورد نیاز را مطابق اتصالات پروژه متصل کنید.

5. پروژه را Build کرده و روی میکروکنترلر **STM32F303VC** پروگرام کنید.
